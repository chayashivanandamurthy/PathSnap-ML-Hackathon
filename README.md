# PathSnap – ML Hackathon

## Project Overview

PathSnap is a distributed machine learning-based
GPS map-matching and route reconstruction project.

## Problem Statement

To reconstruct accurate vehicle routes from noisy
GPS trajectories using machine learning and
road network information.

## Technologies

- Python
- Machine Learning
- HMM
- Viterbi Algorithm
- FastAPI
- GPS Map Visualization
